## About

BounceCoach is an edge-based AR dribbling game that turns solo basketball practice into a rhythm challenge. Ball detection and trajectory tracking run on-device in under 40 ms, and a large language model turns the session metrics into a readable coaching report.

In a pilot study with 24 participants, players reached 28% higher dribble speed consistency and reported 1.6× more fun than with baseline practice.
