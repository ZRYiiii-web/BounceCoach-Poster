BounceCoach

Real-Time Basketball Dribbling Training with On-Site Large Language Model Guidance

An edge-based AR dribbling game that turns solo practice into a rhythm challenge — sub-40 ms on-device feedback during play, and an LLM-generated coaching report afterwards.

Download poster (PDF, 2.3 MB) Read the paper
  • System Camera + edge device, fully on-device inference
  • Latency Under 40 ms feedback loop
  • Pilot study N = 24, baseline vs. BounceCoach
  • Outcome +28% dribble consistency, 1.6× more fun
Poster presented at the IEEE Conference on Virtual Reality and 3D User Interfaces (VRW 2026), Daegu, Republic of Korea.
